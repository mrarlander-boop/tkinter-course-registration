# Регистрация на учебные курсы (Python + Tkinter)

Настольное графическое приложение для регистрации студентов на учебные курсы, разработанное на языке **Python** с использованием стандартной библиотеки **Tkinter**.

## Реализованный функционал

1. **Главное окно приложения**
   - Заголовок: «Регистрация на учебные курсы».
   - Размер окна: `1020 × 780` пикселей (минимальный размер `650 × 500`).
   - Светлая цветовая тема и структурированное разделение интерфейса на логические блоки с помощью `Frame` и `LabelFrame`.
2. **Ввод данных студента (`Label` и `Entry`)**
   - Ф. И. О.
   - Возраст.
   - Номер телефона.
   - Адрес электронной почты.
   - Учебное заведение.
3. **Выбор учебного курса (`ttk.Combobox`)**
   - Основы Python
   - Разработка приложений в Tkinter
   - Веб-разработка
   - Работа с базами данных
   - Компьютерная графика
4. **Выбор формы обучения (`Radiobutton`)**
   - Очное обучение
   - Дистанционное обучение
   - Смешанный формат
5. **Выбор дополнительных возможностей (`Checkbutton`)**
   - Получение сертификата
   - Доступ к видеозаписям
   - Дополнительные практические занятия
6. **Проверка введённых данных (`try/except` и `messagebox.showerror`)**
   - Проверка заполнения всех обязательных полей.
   - Проверка, что возраст является целым числом в диапазоне от 14 до 80 лет.
   - Проверка наличия символов `@` и `.` в адресе электронной почты.
   - Проверка, что номер телефона состоит только из цифр и символа `+`.
   - Проверка выбора учебного курса и формы обучения.
7. **Регистрация и таблица зарегистрированных студентов (`ttk.Treeview`)**
   - Вывод итогового сообщения об успешной регистрации (`messagebox.showinfo`).
   - Отображение списка студентов в таблице со столбцами: `Ф. И. О.`, `Возраст`, `Курс`, `Форма обучения`, `Телефон`.
8. **Управление записями**
   - «Зарегистрироваться»
   - «Очистить форму»
   - «Показать подробности» (также доступно по двойному клику по строке таблицы)
   - «Удалить выбранную запись» (с подтверждением через `messagebox.askyesno`)
   - «Сохранить в файл»
   - «Закрыть программу»
9. **Сохранение данных в файл (CSV / TXT)**
   - Экспорт списка зарегистрированных студентов в CSV (`UTF-8` с BOM, корректно открывается в Excel) или текстовый файл `.txt`.
   - Сохраняются Ф. И. О., возраст, телефон, электронная почта, учебное заведение, курс, форма обучения и дополнительные возможности.
10. **Дополнительное задание — поиск в реальном времени**
    - Фильтрация таблицы по Ф. И. О. или названию учебного курса без учёта регистра с кнопкой сброса и счётчиком записей.

## Структура проекта

```text
.
├── main.py                       # Точка входа приложения
├── course_registration/
│   ├── __init__.py
│   ├── models.py                 # Модель Student и константы списков
│   ├── validation.py             # Функции проверки введённых данных
│   ├── storage.py                # Фильтрация и сохранение в CSV / TXT
│   └── app.py                    # Графический интерфейс Tkinter
└── tests/
    ├── __init__.py
    ├── test_validation.py        # Тесты валидации полей формы
    ├── test_storage.py           # Тесты поиска и экспорта в файлы
    └── test_app.py               # Интеграционные тесты GUI
```

## Требования

- Python 3.10+ (используются только модули стандартной библиотеки: `tkinter`, `csv`, `dataclasses`, `pathlib`, `unittest`).

## Запуск приложения

```bash
python main.py
```

## Запуск автотестов

```bash
python -m unittest discover -s tests -v
```
